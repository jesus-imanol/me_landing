# Paleta: naranja con blanco

Tokens en `web/src/app/globals.css` (`@theme`).

| Token | Hex | Rol |
|---|---|---|
| `crema` | #FFF8F0 | Fondo principal |
| `papel` | #FFFFFF | Superficies, burbujas, botones claros |
| `durazno` | #FFE6D0 | Fondos suaves, halos detrás de los objetos |
| `naranja` | #FF6B1A | **Acento único**: CTA, palabras "coquetas", marquee |
| `mandarina` | #FF9A52 | Centro del sol detrás de Jesús, acentos en la sección oscura |
| `brasa` | #C2410C | Texto naranja con contraste suficiente sobre crema |
| `tinta` | #1F140D | Texto principal y la sección de GitHub (café, no negro puro) |
| `humo` | #7C6A5C | Texto secundario |
| `linea` | #F2E2D2 | Bordes y divisores |

El "sol" (`.sun`) es un degradado radial mandarina a naranja a transparente: le da calidez a cada imagen sin fondo.
