# Paleta: violeta, lavanda y lima

Cambio del 2026-10-15: Jesús pasó de naranja con blanco a la paleta de su referencia (renders 3D morados con acento lima). Tokens en `web/src/app/globals.css` (`@theme`).

| Token | Hex | Rol |
|---|---|---|
| `fondo` | #F5F3FF | Fondo principal (blanco lavanda) |
| `papel` | #FFFFFF | Superficies, burbujas |
| `niebla` | #E6E1FF | Fondos suaves, halos detrás de los objetos |
| `violeta` | #5B47F0 | **Acento principal**: CTA, palabras "coquetas", logo |
| `lavanda` | #A497FF | Centro del sol, contornos de los números |
| `lima` | #D7F23A | Acento de contraste: marquee, años de los proyectos, selección, número de repos. Solo sobre tinta o con texto tinta encima, nunca texto lima sobre blanco |
| `indigo` | #3A2BB8 | Texto violeta con buen contraste (tira que se come, asides) |
| `tinta` | #16132B | Texto principal y sección de GitHub (azul noche, no negro puro) |
| `humo` | #67638A | Texto secundario |
| `linea` | #E2DDF7 | Bordes y divisores |
